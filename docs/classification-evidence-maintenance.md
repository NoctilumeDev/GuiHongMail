## 问题与修复边界

当三个类目有 120、4、4 条确认历史，共用同一发件人和域名时，一个未见过的中文主题只有公共元数据命中。原模型仍可能给出约 99.5% 的分数，并触发自动采纳。已命中两个特征并不能证明这些特征能够区分类别。

现在除了原有分数阈值，还要求至少一个查询特征在预测类目的**样本出现比例**严格高于每个其他类目。按各类样本数量归一化，并在单条样本内去重；不能用大类的原始命中数量替代区分证据。该判断在 Go Domain 中计算，使用本次同一账户的训练输入，不改变 Python 模型输出或伪造校准后的置信度。

高分但没有这种证据时，保存 `UNKNOWN` 建议，返回 `INSUFFICIENT_EVIDENCE`，不指定类目、不自动应用。已有页面会显示原因并保留人工分类入口。有支持证据时仍须满足原阈值及用户按类目开启自动采纳的条件。

这是保守的必要条件，并非语义正确性的充分证明。它可能拒绝仅靠多特征组合才能区分的候选；没有增加中文分词能力，也没有把模型分数解释为真实正确率。历史已应用的分类不会被此次维护自动撤销，仍由用户检查、撤销或纠正。

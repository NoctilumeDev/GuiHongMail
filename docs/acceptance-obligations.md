## 资格收束

每阶段在进入前登记自己的必过集合、机制和负向探针。M5 必须对关键义务发起代表性故障，正常路径通过不代替故障触达。用户批准的四个取消见证不得删减。每个 ID 可有多个独立来源；同一采集器填写相同字符串不能自动证明来源一致。

业务 `UNKNOWN` 是被测状态；按合同准确保留 UNKNOWN 可以支持该断言 PASS。资格 `UNKNOWN/NOT_PROVEN/PENDING/INCONCLUSIVE` 是证明不足，不能算必过项闭合。已承诺的安全/耐久/取消/隔离门缺证据则阻断；仅范围外或非必过扩展可留未知并给再入条件。首败、工具错误、环境阻断、正确拒绝分别保留，后继 PASS 不覆盖历史。

Core 只消费真实事实与封存断言，不靠 `all_passed` 或施工者自评签发工程资格。M1 先证明公开发行物兼容及错误 hash/source/recipient/缺证据的拒绝或非 PASS，再建每阶段采集器。正常阶段通过继续施工；M6 未闭合不得用 STOP 冒充完成。
